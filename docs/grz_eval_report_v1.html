Note on Chunk Differences

GRZ prepends metadata (Chunk ID, Title, DOI, Authors) to each chunk's text before computing the 200-token window. This consumes tokens from the budget and shifts chunk boundaries relative to LGR, resulting in 336,374 chunks vs LGR's 339,308. Retrieval metrics (precision/recall) are not directly comparable due to this difference — only assertion-based answer quality is compared.

6. Summary

GraphRAG Zero V1 (with reasoning-based sampling) achieves competitive answer quality compared to LazyGraphRAG:

  • Overall: GRZ V1 is within 1% of LGR on pass rate (74.6% vs 75.4%)
  • Local questions: GRZ V1 outperforms LGR by 4.4% — its reasoning-based chunk grading helps identify the most relevant passages for document-specific questions
  • Global questions: LGR leads by 5.9% — its graph-based retrieval provides better cross-document synthesis coverage

The reasoning sampling approach uses an LLM (gpt-5-mini) to grade each candidate chunk's relevance before including it in the answer context. This adds latency but improves precision for local, fact-finding questions.
