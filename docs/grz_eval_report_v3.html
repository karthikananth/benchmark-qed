Key v8 Changes from v7

  • Query-based sampling: Automatically classifies queries via LDA as local or global, applying different retrieval strategies
  • Dynamic elbow detection: Replaces fixed dropoff with automatic elbow point detection for community switching
  • Separate local/global tuning: Local uses tight δ=0.1 (focused retrieval), global uses wide δ=0.3 (broader coverage)
  • MMR redundancy penalty: Global queries apply λ=0.9 to penalize redundant chunks, encouraging diversity
  • Dynamic restart: restart_on_dropoff=null lets the system compute optimal restart thresholds

6. Analysis

V3 vs V2: Negligible Difference

The v8 paper settings (query-based sampling, LDA classification, dynamic elbow detection, separate local/global tuning) produced results essentially identical to v7 dropoff. The sophisticated per-query-type parameter tuning did not translate to measurable quality improvements on this corpus.

The Reasoning Gap

The most significant quality difference remains the V1→V2 transition (removing reasoning). The LLM-based chunk grading in V1 provided a ~4% advantage on global questions that neither V2 nor V3 recovered. This suggests that for cross-document synthesis, semantic chunk evaluation (even with a smaller model like gpt-5-mini) provides value that embedding-based methods cannot replicate.

Local vs Global Trade-off

All GRZ versions outperform LGR on local questions (83-86% vs 79.3%), while LGR consistently outperforms on global questions (71.4% vs 61-66%). This reflects a fundamental architectural difference:

  • GRZ: Community-based retrieval with chunk-level selection excels at finding specific passages
  • LGR: Graph-based retrieval with lazy evaluation provides broader thematic coverage for synthesis tasks

Speed vs Quality

GRZ V3 is the fastest system at ~36s/question (vs LGR at ~80s/question), while maintaining competitive local question quality. For latency-sensitive applications focused on specific fact-finding, GRZ offers a compelling speed-quality trade-off.

8. Summary

Three GRZ configurations were evaluated against the same 100 questions and 557 assertions used for the LGR baseline:

  1. GRZ V1 (reasoning/v6): Best GRZ overall at 74.6%, closest to LGR (75.4%). LLM-based chunk grading helps global questions.
  2. GRZ V2 (dropoff/v7): Fastest local results (85.7%) but global dropped 4.3%. Removing reasoning hurt synthesis quality.
  3. GRZ V3 (paper/v8): Query-based sampling with per-type tuning — essentially identical to V2 despite added complexity.

Key conclusions:

  • LGR remains the overall quality leader, driven by a 10+ point advantage on global synthesis questions
  • All GRZ versions outperform LGR on local/specific questions by 4-6 points
  • The reasoning pipeline (V1) provides the best GRZ global performance; removing it (V2/V3) degrades global by ~4% while slightly improving local
  • The v8 paper settings (dynamic elbow, LDA classification, per-type δ/λ) do not improve over simple dropoff (v7)
  • GRZ is 2-4× faster than LGR in search latency
